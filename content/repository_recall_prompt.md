# Recall round: enrich the Master Resume Repository

The Master Resume Repository below is my evidence base. Run one recall round on it: find the facts I have not yet written down, ask me for them, and turn my answers into units.

## Step 1: ask

Read every unit. Ask the 10 questions whose answers would raise the most claims.

- Start with every open Unlock line and every "to confirm". They are questions already waiting.
- Then look for a result with no number, a number with no starting state, and a responsibility with no outcome.
- Then ask for evidence that is missing altogether: a role with few units, a competency in the taxonomy with 1 unit or none.
- One fact per question, answerable in one line from memory. Name the unit ID each question serves, or "new unit" where it would start one.
- Ask for the exact figure, and say you will accept in its place a range, then a relative value ("about 2x"), then a countable proxy (per week, times weeks), then the document or person that could confirm it.

Then stop and wait for my numbered answers.

## Step 2: write the units

When I answer, use only what I said and what the repository already holds. Invent no figure.

- A raised claim: rewrite the unit's Canonical with the new figure, remove the Unlock it answered, and add to Notes the old wording, the new figure and its basis ("recalled, range", "recalled, exact", "confirmed by [document]").
- A new experience: write a new unit with the next free number for that role's prefix.
- A "no" or "do not know": leave the unit as it is and keep its Unlock.
- Keep every existing EU ID. Keep the field names and the heading format exactly.

Return one fenced markdown block that holds only the units that changed or are new. Write each unit in full, under its stack heading line, like this:

````markdown
### **Stack NBD-1 · Adoption recovery and change leadership**

#### **EU-NBD-03 · Stalled-division recovery**

* Tags: CMA, SCM
* Canonical: [the rewritten claim]
* Notes: [old wording, new figure, basis]

#### **EU-NBD-09 · [new unit title]**

* Tags: CMA
* Canonical: [the new claim]
````

The stack heading is there so the Repository page knows where each unit goes. Do not repeat the stack claim or any unit that did not change.

Below the block, list in 3 lines or fewer: units raised, units added, questions still open.
